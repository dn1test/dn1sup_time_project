# Changelog (Лог изменений)

Лог изменений **DN1Sup Time Project** (`dn1sup_time_project`).
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

## [0.7.7] — 2026-10-17

### DN1Sup Time Project (v0.7.7)
- **Обновление только через GitHub** — убрана проверка локальной папки
  разработки (local-first): кнопка «Проверить обновления», пункт меню и
  фоновая проверка при старте ходят только в GitHub Releases + registry.json;
  из апдейтера удалены локальная установка (.rbz на лету, копирование в
  Plugins) и трёхстороннее сравнение источников. Для соседних расширений и
  Store менеджера, зовущих старые методы общего апдейтера, оставлены
  заглушки-делегаты с GitHub-поведением.

## [0.7.6] — 2026-10-16

### DN1Sup Time Project (v0.7.6)
- **Фирменная плитка DN1Sup в шапке GUI** — та же плитка, что в каталоге
  Extension Store (цветной квадрат, знак с «воздухом»); работает в светлой
  и тёмной теме. Источник — `dn1sup_extensions` (`tools/make_icons.rb`).
## [0.7.5] — 2026-10-16

### DN1Sup Time Project (v0.7.5)
- **Фирменный знак тулбара DN1Sup** — единый стиль каталога Extension
  Store: часы со стрелками (sky), прозрачный фон, вырезы — настоящая прозрачность
  (SVG-маска; PNG 16/24 — альфа-канал). Источник знака —
  `dn1sup_extensions` → `icons/products/` (`tools/make_icons.rb`).


## [0.7.4] — 2026-10-16

- feat(icons): векторная иконка тулбара `timer.svg` в фирменном стиле
  (синий секундомер) — SketchUp ≥ 16 использует SVG, старые версии
  откатываются на PNG-фолбэк `timer_16.png`/`timer_24.png`;
  растры перегенерированы скриптом `tools/make_icons.rb`.

## [0.7.3] — 2026-10-16

- feat(gui): кнопка языка показывает **целевой** язык (`EN` при русском
  GUI, `RU` при английском), чтобы было видно, на что переключишься.

## [0.7.2] — 2026-10-16

- feat(gui): переключатель языка в шапке — одна кнопка с глобусом
  и текущим языком (`RU`/`EN`) вместо двух кнопок; подсказка
  локализована (`lang.toEn`/`lang.toRu`).

## [0.7.1] — 2026-10-16

- chore(updates): убран переходный чек маркера `.sketchup_dev.json` из
  `dev_source?` (`shared/dn1sup_updater.rb`) — период миграции со старых
  `_dev`-установок завершён; self-update рабочей копии определяется только
  по пути загрузки (код вне папки `Plugins` SketchUp).

## [0.7.0] — 2026-10-15

- feat(updates): самообновление расширения — кнопка проверки обновлений
  в шапке диалога; проверка сначала смотрит локальную папку разработки,
  затем GitHub Releases, установка прилетевшего `.rbz` одной кнопкой
  (расширен `shared/dn1sup_updater.rb`).
- refactor!: убраны dev-кнопки обновления из рабочей копии и hot reload
  из UI (`dialog.rb`, `main.rb`, `ui/index.html`, `useSketchupBridge.js`) —
  разработка ведётся в рабочей копии под тем же id («Обновить из рабочей
  копии» / reload), self-update рабочей копии отключён (`dev_source?`).
- chore: единый апдейтер `Dn1sup::Updater` v3 во всех местах проверки
  обновлений; добавлен `author` в `registry.json`.

## [0.6.0] — 2026-10-13

- Удалён функционал dev/prod (второй id `dn1sup_time_project_dev`): удалены
  `DEV_BUILD`, поле `dev_build` в данных трекера и бейдж DEV в шапке.
  Разработка — рабочая копия под тем же id («Обновить из рабочей копии» /
  reload); self-update рабочей копии отключён по пути загрузки
  (`Dn1sup::Updater.dev_source?`); файлы `.sketchup_dev.json` удалены.
- feat(gui): кнопка паузы/продолжения перенесена в шапку карточки модели
  рядом с периодом; кнопки обновления/папки/dev убраны из панели управления.

## [0.5.3] — 2026-10-10

- feat: dev/prod placement split, self-update guard for dev installs; v0.5.3
